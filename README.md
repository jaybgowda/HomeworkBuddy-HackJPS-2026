# HomeworkBuddy-HackJPS-2026
A logbook for tracking tasks that has its own fun system to make sure you do them every day and never forget your tasks again.
# My Inspiration
I got inspired to make this when I saw my friends struggle to keep up with day-to-day tasks.
# Why should you use it?
Users will get to track down all of their assignments, ranging from homework to personal chores.
# How I built it
I built HomeworkBuddy through Visual Studio Code as my IDE in multiple organized files with HTML and JavaScript as my programming languages.
# Challenges we ran into
One challenge includes the leveling system bugging, meaning I just wouldn't get the level up. Another one was the challenge of keeping the calendar clean and able to function smoothly.
# Accomplishments that I'm proud of
I'm proud that I took the step to create something that would help lots of my peers, and I'm also proud I took my ideas to reality through this Hackathon.
# What I learned
I learned the challenges programmers go through while coding, such as the amount of trial and error one must take in order to create a working mechanism.
# What's next for HomeworkBuddy
As of now, the main functionality is good, but I would like to take the "Buddy" system to the next level. As in, making customizable avatars for a pet buddy when you level up every few levels. HomeworkBuddy would be better with fun pop-ups to play after finishing your tasks and a streak system so that users can make sure to log their tasks every day.
